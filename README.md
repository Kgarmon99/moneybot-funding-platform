# MoneyBot Funding Accelerator Platform

A unified platform to accelerate fundraising for MoneyBot.

## Features

1. **Funding Dashboard** — Real-time view of all active deals, stages, deadlines
2. **Grant & Accelerator Matcher** — Auto-find and filter opportunities by fit
3. **Warm Intro Network Mapper** — Visualize who knows who, track intro paths
4. **Investor Data Room** — Shareable portal with deck, metrics, and docs

## Tech Stack

- React + TypeScript frontend
- Node.js/Express backend
- SQLite database (simple, portable)
- Deploy: Static site + API server

## Quick Start

```bash
npm install
npm run dev
```
